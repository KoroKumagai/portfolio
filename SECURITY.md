# Security Policy

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

Report them privately via GitHub's [private vulnerability reporting](https://github.com/KoroKumagai/portfolio/security/advisories/new) (the **Security** tab → **Report a vulnerability**).

Please include as much of the following as you can:

- The affected URL or file path
- A description of the issue and its impact
- Steps to reproduce, or a proof of concept

## Scope

In scope:

- The source code in this repository (the `main` branch)
- The live site at [https://bbbb.dev](https://bbbb.dev)

Out of scope:

- Vulnerabilities in third-party services that host or support the site (GitHub, Cloudflare); please report those to the respective vendor
- Denial of service, including volumetric attacks and load testing
- Social engineering or phishing
- Reports from automated scanners without a demonstrated impact

Only the latest version on `main` and the live site are supported; earlier versions do not receive fixes.

## What to Expect

This project is maintained by one person, so responses are best-effort. I aim to:

- Acknowledge your report within 7 days
- Keep you informed as the issue is investigated and fixed
- Credit you in the published security advisory, unless you prefer to remain anonymous

Please give me a reasonable amount of time to fix the issue before disclosing it publicly.
